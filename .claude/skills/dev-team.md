# Dev Team

## Team Structure
- **Lead Developer**: Architecture decisions, code reviews
- **Frontend Developers**: React components, state management, UI/UX
- **Backend Developers**: API design, database, authentication
- **Full Stack**: Cross-functional work

## Workflows
- **Branching**: `feature/*`, `bugfix/*`, `hotfix/*` from `main`
- **PR Process**: Require review + CI pass before merge
- **Code Review**: At least 1 approval, address all comments
- **Testing**: Unit tests for new features, integration for APIs

## Communication
- Daily standups for sync
- Async updates via PR comments and issues
- Knowledge sharing sessions bi-weekly

## Standards (from CLAUDE.md)
- Clean Code: SOLID, DRY, KISS
- Security: OWASP best practices
- Workflow: Professional Git/GitHub workflows
- Stack: MERN (Node.js, Express, React) and Python/Django

## Onboarding Checklist
- [ ] Repository access
- [ ] Local environment setup
- [ ] Review CLAUDE.md standards
- [ ] Understand skill toolkit
- [ ] First PR with mentor
