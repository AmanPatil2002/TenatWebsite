# Engineering Skills Toolkit

This directory contains specialized skills to enforce professional software engineering standards across the project.

## Skills

- `architecture.md`: System design, SOLID, and scalability principles.
- `clean-code.md`: Code quality, naming conventions, and readability.
- `security.md`: OWASP top 10, AuthN/AuthZ, and secure practices.
- `devops.md`: CI/CD pipelines, Docker, and cloud infrastructure.
- `testing.md`: TDD and testing frameworks (Jest, etc.).
- `git.md`: Branching, commit messages, and PR workflow.
- `performance.md`: Bottleneck analysis and optimization.
- `api.md`: API design and standards.
- `database.md`: DB integrity, schema design, and query optimization.
- `frontend.md`: React, component libraries, and web accessibility.
- `backend.md`: Express, middleware, and error handling.
- `logging.md`: Metrics and observability.
- `documentation.md`: Technical documentation standards.
- `communication.md`: Collaborative norms.
- `agile.md`: SDLC and project management.
- `refactoring.md`: Techniques for improving existing code.
- `tooling.md`: Automating development tasks.
