# Engineering Standards & Skills Toolkit

This project utilizes a standardized set of engineering skills, managed within `.claude/skills/`.

## Standards
- **Clean Code:** Adhere to SOLID principles, DRY, and KISS.
- **Security:** Follow OWASP best practices.
- **Workflow:** Use professional Git/GitHub workflows.
- **Stack:** MERN (Node.js, Express, React) and Python/Django.

## Skills List
1.  **Architecture:** System design and component boundaries.
2.  **Clean Code:** Maintainable, readable, and testable code.
3.  **Security:** Authentication, authorization, and data protection.
4.  **DevOps:** Deployment, CI/CD, and infrastructure-as-code.
5.  **Testing:** TDD, unit/integration testing patterns.
6.  **Git:** Best practices for branching, merging, and PRs.
7.  **Performance:** Profiling, optimization, and resource management.
8.  **API Design:** RESTful standards, versioning, and documentation.
9.  **Database:** Schema design, optimization, and query integrity.
10. **Frontend:** React patterns, state management, and accessibility.
11. **Backend:** Node/Express best practices, middleware, and error handling.
12. **Logging/Monitoring:** Observability and incident response.
13. **Documentation:** Technical writing for codebase and project.
14. **Communication:** Professional interpersonal and team interaction.
15. **Agile:** SDLC, task management, and sprint cycles.
16. **Refactoring:** Legacy code improvement techniques.
17. **Tooling:** Automating routine development tasks.

All contributions must align with these standards.
